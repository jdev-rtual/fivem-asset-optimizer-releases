# FiveM Asset Optimizer: releases

Built downloads of **FiveM Asset Optimizer**, a texture optimizer and GTA-style 3D viewer for FiveM assets
(`.ydr`, `.ydd`, `.yft`, `.ytd`).

Grab the latest `AssetOptimizer.exe` from [Releases](../../releases/latest). Installed copies update
themselves from here. Each exe has a matching `.sha256` file, and the app refuses any download that doesn't match it.

Requires the .NET 10 Desktop Runtime (x64). The source code is maintained privately.
